# DEBAN - 現場のための職人手配管理アプリ LP

## プロジェクト概要

DEBANは、工事会社向けの施工管理・職人手配アプリのランディングページ（LP）です。ホワイトボードやExcelで手配管理をしている工事会社をターゲットに、手配業務の効率化とコンバージョン最大化を目的としたLP設計となっています。

### プロジェクトの目標

- **トライアル申し込み**の最大化
- **デモ視聴**への誘導
- **商談予約**の獲得

### ターゲットユーザー

- ホワイトボード、手帳、Excelで職人の手配管理をしている工事会社
- ITに詳しくない現場責任者
- 電気工事、防水工事などの専門工事会社

## 🎯 主な機能・特徴

### ✅ 完成済み機能

1. **ファーストビュー（FV）**
   - キャッチコピー: 「工事会社のアドバイスから生まれた、現場のための手配管理アプリ」
   - 従業員1〜100名の会社に最適を明記
   - スマートフォンから簡単アクセスを強調
   - 3つのCTA: 無料トライアル、デモ動画、ログイン
   - レスポンシブ対応（PC/タブレット/スマホ）
   - DEBANロゴをテキスト表示（画像削除）

2. **3つの選ばれる理由**
   - 現場発想の設計
   - 圧倒的な低価格（月額5,000円〜）
   - 迷わないシンプル設計
   - ホバーアニメーション付きカード表示

3. **顧客の課題セクション（再構成版）**
   - 写真と課題を1つの枠に統合した新デザイン
   - ホワイトボード管理の実際の画像 + 課題説明
   - Excel管理のアイコン + 課題説明
   - 電話確認のイメージ + 課題説明
   - 機会損失の可視化

4. **解決策の提示（機能再構成版）**
   - 機能01「現場の進捗を見える化」: 案件管理画面（project-management.png）
   - 機能02「手配状況を一目で把握」: 案件一覧画面（schedule-list.png）
   - 機能03「直感的なスケジュール管理」: スケジュールカレンダー（schedule-calendar.png）
   - 各機能に詳細な説明文を配置
   - スケジュール管理の見える化
   - 確認の手間削減
   - 作業員不足の解消につながる

5. **デモ動画セクション**
   - 30秒でわかるDEBANの使いやすさ
   - 動画埋め込みエリア
   - CTAボタン配置

6. **導入の流れ**
   - 3ステップでの導入プロセス可視化
   - ステップごとのアイコン表示

7. **料金プラン（4プラン構成）**
   - スタータープラン: ¥5,000/月（5ID以下）
   - スタンダードプラン: ¥10,000/月（30ID以下）- 人気プラン
   - ビジネスプラン: ¥15,000/月（30ID〜100ID）
   - エンタープライズプラン: ¥20,000/月（無制限）
   - 各プランに自社ID数、他社ID数、おすすめ企業を表示
   - 14日間無料トライアル

8. **よくある質問（FAQ）**
   - アコーディオン形式で6つの質問
   - クリックで開閉するインタラクション

9. **お問い合わせフォーム**
   - 会社名、お名前、メールアドレス、電話番号の入力欄
   - お問い合わせの種類選択（今すぐ話を聞きたい/資料が欲しい/契約について/その他）
   - お問い合わせ内容のテキストエリア
   - レスポンシブ対応の美しいフォームデザイン
   - プライバシー保護メッセージ付き

10. **最終CTA**
   - 無料トライアル申し込みフォームへの誘導
   - 商談日程調整リンク
   - 4つの安心ポイント表示

11. **フローティングCTAボタン**
    - スクロール時に表示される固定CTAボタン
    - トライアル申し込みへの即座の誘導

12. **レスポンシブデザイン**
    - PC、タブレット、スマホに完全対応
    - 各デバイスに最適化されたレイアウト

## 🚀 機能実装の詳細

### JavaScript機能

1. **スムーススクロール**

   - ヘッダー高さを考慮した位置調整

   - クリックで開閉

   - Google Analyticsとの連携準備済み

6. **ヘッダーシャドウ**
   - スクロール時に動的にシャドウを調整

7. **デバイス判定**
   - モバイル/タブレットの自動判定
   - bodyタグにクラス付与

8. **パフォーマンス測定**
   - ページロード時間の計測
   - コンソールにメトリクス出力

## ⚙️ 導入方法

### 1. ファイルの配置

プロジェクトファイルをWebサーバーにアップロードします。

```bash
# ファイル構造を維持したままアップロード
├── index.html
├── css/
│   └── style.css
└── js/
    └── main.js
```

### 2. 外部リンクの設定

`index.html`内の以下のリンクを実際のURLに変更してください:

```html
<!-- 無料トライアル申し込みフォーム -->
<a href="https://forms.gle/your-trial-form" ...>

<!-- 商談日程調整 -->
<a href="https://calendly.com/your-meeting-link" ...>

<!-- ログイン -->
<a href="https://app.deban.com/login" ...>
```

### 3. 画像の追加

以下のプレースホルダーに実際の画像を配置してください:

- カレンダー一覧画面のスクリーンショット
- 簡単登録画面のスクリーンショット
- 職人管理画面のスクリーンショット
- デモ動画の埋め込み
